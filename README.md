# 和時計 ― 不定時法シミュレーター

江戸時代に用いられていた「不定時法」を、実際の天文計算（日の出・日の入り時刻）に基づいて再現した、HTML + JavaScript 製の和時計シミュレーターです。

外部ライブラリを一切使わず、`index.html` / `style.css` / `script.js` の3ファイルだけで動作します。

## 不定時法について

江戸時代の時刻制度は、日の出（明六つ）から日の入り（暮六つ）までの「昼」と、日の入りから日の出までの「夜」を、それぞれ6等分して「一刻（いっとき）」とする方式でした。そのため一刻の長さは季節によって伸び縮みします（夏は昼の一刻が長く、冬は夜の一刻が長い）。

このシミュレーターでは、緯度・経度から太陽の日の出・日の入り時刻を計算し（Sunrise equation に基づく実用精度の天文計算）、その日その場所での実際の一刻の長さを求めて時刻を表示します。

文字盤は「割駒式」和時計を模しており、針は24時間かけて等速で一周する一方、十二支・鐘の数（九つ・八つ…）を示す目盛りの駒は、季節ごとの昼夜の境目に合わせて位置を変えます。

## 主な機能

- 現在時刻を不定時法（鐘の数表記＋十二支表記）に変換して表示
- 日付スライダーによる季節変化のシミュレーション（一刻の長さが動的に変わる様子を確認できます）
- 「江戸（東京）」固定モードと、位置情報を使った「現在地」モードの切り替え
- 一日を約18秒に早送りして、針と目盛りの動きを通しで確認できる再生機能

## ファイル構成


## ローカルでの確認方法

ブラウザで `index.html` を直接開くか、簡易サーバーを立てて確認してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages での公開手順

1. このリポジトリを GitHub にプッシュする
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」に設定し、ブランチを `main`（フォルダは `/root` すなわちリポジトリ直下）に指定して **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 実装メモ・注意点

- 日の出・日の入り時刻の計算は大気差・太陽視半径を考慮した実用精度の近似式（誤差はおおむね±1分程度）を使用しています。均時差・太陽赤緯の年変化も織り込み済みです。
- 「明六つ」「暮六つ」は日の出・日の入りの時刻そのものを基準としています（史実には薄明を基準とする説もありますが、シンプルさを優先しました）。
- 緯度・経度の変化によって日の出入りが定義できない極域（白夜・極夜）では、その旨を表示します。
